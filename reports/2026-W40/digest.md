## 本周洞察

- **"免训练/免调参"正在向更多领域渗透**：TabPFN/TabICL 在表格数据上击败调优 XGBoost，与 LLM 领域"基础模型替代专用训练"的趋势一致。对 Agent 开发者而言，这意味着在结构化子任务上应优先尝试基础模型，把调参预算留给真正需要的地方。
- **LLM 流水线框架正在跨生态扩散**：DSPy 被完整移植到 BEAM（Imp），说明"声明式 prompt 编排 + 自动优化"已从 Python 单点走向多语言生态。若你的 Agent 后端不在 Python 上，现在有了更多可借鉴的移植样本。
- **自动化有边界，工程判断仍不可替代**：本周两篇文章（代码审查的不可自动化部分、可塑软件的用户能动性）共同指向一个主题——AI 能自动化"检测"和"生成"，但设计讨论、用户定制、架构决策仍需人的判断。在构建 Agent 工具时，应把 AI 定位为增强而非替代。
